# noble-ciphers

`@noble/ciphers` is built and tested by the maintained Noble workflow. The
adapter covers AES ECB, CBC, CTR, CFB, GCM, GCM-SIV, SIV-CMAC, KW, and KWP;
ChaCha20 and ChaCha20-Poly1305; XChaCha20-Poly1305; and Salsa20.

See [noble cryptography](noble.md) for the supported build commands and pinned
version policy.
